# سباق المعلومات

لعبة ويب عربية (RTL) لسباق أسئلة إسلامية بين لاعب وخصم: سباق من 10 أسئلة، 15 ثانية لكل سؤال، إجابة صحيحة تقدّمك على مضمار متحرك، والأسرع يجمع نقاطاً أكثر.

## طريقة اللعب

- سباق سريع ضد الكمبيوتر (سراج): 10 أسئلة، 15 ثانية لكل سؤال.
- إجابة صحيحة قبل الخصم = 10 نقاط وخطوة للأمام، وبعده = 5 نقاط.
- إجابة خاطئة أو انتهاء الوقت يوقف تقدّمك في ذلك السؤال.
- عند التعادل يُلعب سؤال فاصل مفاجئ حتى يحسم الفائز.
- القدرات الخاصة (مرة في كل سباق): تخطّي سؤال صعب، تجميد الخصم 5 ثوانٍ، مضاعفة النقاط.
- تحدٍّ يومي: 5 أسئلة جديدة كل يوم (محاولة واحدة يومياً).
- بطولة موسمية: 3 جولات إقصائية ضد سراج وحافظ وقارئ.

## بنك الأسئلة

- 100 سؤال موثّق بمصدره في 6 فئات: قرآن، سيرة، فقه، حديث، تاريخ إسلامي، عقيدة.
- الدرجات: سهل / متوسط / صعب. الأنماط: اختيار من متعدد، صح/خطأ، ترتيب، إكمال آية.
- كل سؤال يحمل مرجعه (سورة وآية، أو صحيح البخاري/مسلم برقم الحديث) ويظهر داخل اللعبة.
- الهدف 500 سؤال موثّق؛ التوسعة المتبقية تحتاج مراجعة بشرية لكل سؤال قبل إضافته، ولذلك لم تُضف أسئلة غير موثّقة.

## الأوضاع والتقدّم

- سباق عبر الإنترنت (مطابقة عشوائية) وغرف أصدقاء خاصة (رمز غرفة ورابط دعوة) وبطولات: الواجهات جاهزة ومبنية على Supabase Realtime، وتعمل فور توفر بيانات مشروع Supabase (الرابط والمفتاح العام anon key) في `config.js` — وهي غير متوفرة بعد، ولم يُخترع أي رابط أو مفتاح.
- الدخول بـ Google فقط (Google Identity Services) عند توفر معرّف عميل Google في `config.js`؛ لا دخول برقم هاتف.
- التقدّم محفوظ محلياً: نقاط وخبرة (XP) وألقاب إسلامية وإنجازات ولوحة صدارة محلية وملف لاعب بإحصاءاته.
- الوضع الليلي وإشعارات داخل اللعبة.

## التشغيل محلياً

```bash
node server.mjs   # ثم افتح http://localhost:3000
```

أو للبناء فقط:

```bash
node build.mjs    # ينتج مجلد dist/
```

## الإصدارات

يُبنى كل إصدار تلقائياً عبر `.github/workflows/release.yml` (بناء + حزم + إنشاء GitHub Release عند دفع وسم `v*` أو التشغيل اليدوي).

## البنية

- `index.html` — الواجهة العربية RTL
- `styles.css` و`features.css` — التصميم (ذهبي وأخضر زمردي)
- `app.js` — منطق اللعبة
- `questions.js` — بنك الأسئلة الموسّع
- `config.js` — إعدادات الربط (Supabase وGoogle) — فارغة حتى تتوفر البيانات الحقيقية
- `build.mjs` — بناء نسخة `dist/` الثابتة
- `server.mjs` — خادم تطوير محلي
